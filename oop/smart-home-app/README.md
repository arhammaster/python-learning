# Smart Home

## Google Home 

It is a controller for home which allow to access home


## Home
- home can allow to add and remove device
  - `add-smart-switch` allow to add smart switch into home
- home can allow to action
  - `turn-on-all-switch` turn on all smart switch
  - `turn-off-all-switch` turn off all smart switch 

## Device 

A device is a parent class implemented by the smart devices, It has it's on `name`.

### Smart Switch 

- implement device class
- can turn `on / off` devices.
